# Session-Start

1. `git pull` im **Projekt-Repo** der Domain.  
2. Lesen: Tagesabschluss/CURRENT/PLAN/WORKFLOW (Namen je Projekt).  
3. Live gegen Repo prüfen: Schema-Anzahl, Disclaimer, robots-Sitemap-Zeile, zuletzt geänderte UI.  
4. CDP-Port wählen: belegt = anderen Port. Dokumentieren.  
5. Chrome nur für diese Domain-Session.  
6. WP-Admin: aktuelle Zugangsdaten vom Auftraggeber, keine Alt-Chats.  
7. Erst dann ein Write nach `playbooks/02-ein-live-schritt.md`.
