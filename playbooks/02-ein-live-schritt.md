# Ein Live-Schritt

A. Prewrite unter `archive/YYYY-MM-DD/prewrite/` (alter Stand, ID, Ort).  
B. Genau **ein** logischer Change, sichtbar in der Admin-UI (CDP).  
C. Frontend verifizieren, Cache-Bust.  
D. Fehler: Rollback + Wiedervorlage. Keine stillen Workarounds.  
E. Erfolg: Archiv-Markdown + CURRENT/PLAN + Push ins **Projekt-Repo**.

Nicht: zwei Plugins in einem Batch, Slider plus robots, „schnell noch“.
